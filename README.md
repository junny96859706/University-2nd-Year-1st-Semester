### 1. Visual Studio 버전 차이 및 빌드 도구 미설치 이슈 (2026-05-11)
* **문제**: 노트북(VS 2026)에서 작업하던 프로젝트를 데스크톱(VS 2022)에서 실행 시 `v145` 빌드 도구를 찾을 수 없다는 에러 발생.
* **원인**: 프로젝트 설정 파일(`.vcxproj`)에 상위 버전의 빌드 도구가 지정되어 있어 하위 버전 IDE에서 호환되지 않음.
* **해결**: 
  - `.gitignore` 설정을 수정하여 프로젝트 설정 파일이 Git에 포함되도록 개선.
  - 작업 환경을 최신 버전(VS 2026)으로 통일하고, 누락된 빌드 도구 패키지를 재설치하여 장비 간 동기화 완료.
